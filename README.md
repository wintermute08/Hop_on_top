# Hop on Top

2D 탑 등반 PvP 게임 (Phaser 3 + TypeScript + Vite). 미니멀 그래픽 위에 물리·연출·심리전으로 손맛을 만든다.

## 실행
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 프로덕션 빌드
```

## 조작
- **← →** 이동 · **Shift** 달리기 · **Space** 점프(웅크림 후 도약)
- **Z** 크로스 펀치(강) · **X** 레프트 잽(빠름) — 연속 명중 시 콤보로 임팩트 증가
- **C** 캐릭터 색 변경 · **E** 에디터 · **M** 메뉴

## 구성
- 메뉴 → 솔로 플레이 / 맵 만들기 / 기본 맵 / 코드 불러오기 / 방 만들기·참가(멀티 대비 스캐폴드)
- **레벨 에디터**: 32px 그리드에 블록·함정·이동발판·시작·정상(깃발) 배치, 맵 코드로 복붙 공유(슈마메 코스코드 방식)
- **카메라**: 관성 추적 + Look Ahead, 타격/착지 스프링 연출
- **레벨**: 움직이는 발판, 가시 함정, 체크포인트 복귀, 정상 깃발 도달 시 승리

자세한 기획은 [GDD.md](./GDD.md) 참고.
